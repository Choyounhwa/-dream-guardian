# 꿈의 수호신 (Dream Guardian) - 게임 기획서 (GDD)

> **프로젝트명**: Dream Guardian (꿈의 수호신)
> **태그라인**: "생각하는 힘이, 나를 지킨다"
> **장르**: 체감형 피트니스 교육 RPG (Ring Fit Adventure 스타일)
> **플랫폼**: 모바일 웹 (PWA), 데스크톱 브라우저
> **타겟 유저**: 초등~중등 학생 (수학 학습 + 신체 활동)

## 1. 게임 컨셉

### 1.1 핵심 아이디어
- 웹캠 앞에서 **실제 운동**(제자리 달리기, 스쿼트, 점프, 팔 스트레칭)을 하면서
- **수학 문제**를 풀어 수호신에게 마나를 공급하고
- 수호신이 모은 마나로 **보스 몬스터를 물리치는** 체감형 RPG

### 1.2 세계관 (몽계 - 꿈의 세계)

**배경**: "몽계"는 아이들의 꿈으로 만들어진 세계. 이 세계에 어둠이 침투하면서 꿈이 무너지기 시작한다.

**주인공**: 아이의 꿈을 지키기 위해 태어난 작고 약한 수호 정령. "사고의 빛"(수학 문제 정답 시 발생하는 에너지)을 흡수하며 성장한다.

**4대 몬스터 + 최종 보스**:

| 챕터 | 몬스터 | 정체 | 수학 영역 |
|-------|--------|------|----------|
| Ch.1 | **포겟 (Forget)** | 기억을 지우는 안개 괴물 | 덧셈/뺄셈 |
| Ch.2 | **후다닥 (Hurry)** | 서두르게 만드는 번개 괴물 | 곱셈/나눗셈 |
| Ch.3 | **뒤죽박죽 (Jumble)** | 숫자를 뒤섞는 만화경 괴물 | 분수 |
| Ch.4 | **에라 (Give-up)** | "그냥 포기해"를 속삭이는 그림자 | 소수 |
| Ch.5 | **나이트메어 (Nightmare)** | 실패와 좌절을 먹고 자라는 최종 보스 | 전 영역 종합 |

**엔딩 메시지**: "실패는 너의 힘이 아니야. 다시 도전하는 그 순간이, 바로 나의 힘이 되는 거야."

## 2. 게임 루프 (Core Loop) - #229 확정 사양

> **현행 기준: [SPEC-ROUTINE-VERIFY-001 / #229]** Phase A는 정답·오답·타임아웃 합계 10문제를 각 라운드의 최종 판정과 정산까지 완료한 뒤 종료한다. 보스 처치와 승리는 Phase B에서만 허용하며, 10번째 라운드에서 HP가 0이면 게임오버가 우선하고 11번째 문제는 출제하지 않는다.

```text
메뉴 → 프레임 조정/카운트다운
  → Phase A: RUN_QUESTION → ANSWER_SELECT
      → 정답: STAR_COLLECT ┐
      → 오답/timeout: HAZARD_EVADE ┘
      → ROUND_RESOLVE (총 10회)
  → HP <= 0: GAMEOVER
  → HP > 0 && 10회 정산 완료: Phase B 보스 결전
```

### 2.1 Phase A 상태·시간·입력·화면·자원·전환 계약

> BPM 120(1박 = 0.5초). 모든 시각은 pause 시간을 제외한 세션 활성 시간을 사용한다. 프레임 경계에서는 **입력 처리 → 노트/공격 판정 → 만료 처리 → 라운드 정산 → 상태 전이** 순서를 지킨다.

| 상태 | 시간 계약 | 입력 및 중복 방지 | 화면 | 자원 변경 | 전이 조건 |
|---|---|---|---|---|---|
| **RUN_QUESTION** | Phase A 시작 마나 0. 0.5초 슬롯 8개, 가장 빠른 종료 4.0초. 미동작 시 진행도 증가 없이 대기 | 선택한 운동 또는 fallback. 슬롯당 최대 1회, `roundId+slot` 중복 차단 | 문제/TTS 각 1회. 1~2슬롯 접근, 3~8슬롯 고정, 실제 `0/8~8/8` 표시 | 없음 | 8번째 슬롯 종료 후에만 `ANSWER_SELECT` |
| **ANSWER_SELECT** | 최대 1.0초(2박) | 한 팔 Zone 4/5 무체류 즉시 선택. 양팔 동시 유효는 미선택. 정확히 1.0초 경계는 입력 후 timeout 검사 | 문제와 좌/우 답안. 별·장판·구형 자세 레시피 미표시 | 답 상태만 잠금 | 정답은 `STAR_COLLECT`, 오답/timeout은 `HAZARD_EVADE` |
| **STAR_COLLECT** | 7개 착지 `t=0.5, 1.0, ..., 3.5`. 최종 유효 경계 `t=3.90`, 정산 전이 `t=4.00` | 지정 부위/존 입력. 한 입력은 가장 가까운 미판정 노트 1개에만 귀속. 동률이면 이른 착지, 작은 `noteId` 순. `noteId`당 판정 1회 | 7개 노트 비행, 목표 존, 판정 결과. 장판 미표시 | 판정/별가루를 라운드 버퍼에 기록 | 마지막 입력·만료 처리 후 `t=4.00`에 `ROUND_RESOLVE` |
| **HAZARD_EVADE** | 경고 `0 <= t < 2.60`, 입력창 `2.60 <= t <= 3.40`, 판정 `t=3.50`, 정산 전이 `t=4.00` | `left_step`(왼발 들기), `right_step`(오른발 들기), `jump` 중 시드 기반 1개. 틀린 선행 입력은 기회를 소모하지 않고 성공은 잠금. `attackId`당 결과 1회 | 단일 공격 경고 장판과 성공/실패 피드백. 별 미표시 | 성공 0, 실패 HP -25를 라운드당 최대 1회 | 결과 확정 후 `t=4.00`에 `ROUND_RESOLVE` |
| **ROUND_RESOLVE** | 원자적 1회 정산 | 입력 차단, `roundId` 중복 정산 차단 | 최종 판정과 자원 변화 HUD 반영 | 결과/자원 반영 후 완료 문제 수 +1 | HP <= 0이면 게임오버, 아니고 10문제면 Phase B, 아니면 다음 `RUN_QUESTION` |

### 2.2 판정 및 자원 계약

- 노트 오차 `e = 입력 시각 - 착지 시각`: Perfect `|e| <= 0.12`, Good `0.12 < |e| <= 0.25`, Late `0.25 < |e| <= 0.40`, 유효 입력 없이 `착지+0.40초`를 초과하면 Miss다.
- `t=3.90` 입력은 마지막 Late로 먼저 처리하고 `t=4.00`에 정산한다. 기존 `3.5초 만료 즉시 정산` 요구는 폐기한다.
- 별가루는 노트당 Perfect 4 / Good 3 / Late 2 / Miss 0이다. 정답 라운드 최대 28, Phase A 최대 280이며 Phase A에서는 소비하지 않는다.
- 정답 기본 보상은 별 판정과 무관하게 마나 +25, 콤보 +1, 미니언 +1이다. 미니언은 3명으로 시작해 최대 13명이다.
- 오답/timeout은 콤보를 0으로 만들지만 직접 HP 피해와 보스 직접 반격은 없다. 단일 회피 실패만 HP -25를 적용한다.
- 정답 직접 보스 피해는 0이다. 마나 100 도달 시 즉시 100을 소비하고 수호신 스펠 1회로 보스 HP -4를 적용하되 Phase A에서는 승리 전환하지 않는다.
- 정답 10회 시 스펠은 최대 2회이므로 Ch.1~4 보스는 최소 HP 2, Ch.5 보스는 최소 HP 12로 Phase B에 진입한다.
- 10번째 최종 판정과 정산 후 HP를 먼저 검사한다. HP가 0이면 게임오버, HP가 남으면 잔여 HP/보스 HP/마나/수호신/미니언/별가루 스냅샷을 Phase B에 1회 인계한다.
- `balance_left/right`는 미채택한다. #239는 superseded 처리하며 런타임 선택·화면·통계에서 제외한다.

#### 2.5 비트매니아식 싱크(Sync) 판정 & 어긋남(Stumble) 사운드 메커니즘

- **Perfect (정박 ±0.12초 이내)**:
  - 맑고 풍성한 정격 음정의 기타 서스테인과 펀치력 있는 드럼 사운드가 100% 게인으로 믹싱되어 합주 쾌감 극대화.
- **Good / Late (박자 불안정 ±0.25초 / ±0.40초)**:
  - 음량은 유지되나 피치가 미세하게 떨리거나 약간 플랫(b)된 톤으로 출력.
- **Miss (판정창 만료 또는 엇박)**:
  - **기타 삑사리**: 프렛을 잘못 긁는 노이즈(`Fret Scratch`) 및 피치가 꺾이는 불협 글리치 사운드 출력.
  - **드럼 엇박**: 박자가 절룩거리는 둔탁한 림샷 노이즈 출력.
- **무동작 사운드 연출**:
  - 메인 악기 트랙 음소거(Mute), 조용한 가이드 메트로놈 틱만 남아 연주가 끊어지는 느낌 제공.

## 3. 시스템 설계

### 3.1 전투 시스템

| 파라미터 | 값 |
|----------|-----|
| 플레이어 HP | 100 |
| 보스 HP (Ch.1~4) | 10 |
| 보스 HP (Ch.5 캄캄대왕) | 20 |
| 정답 시 마나 획득 | +25 |
| 마법 시전 비용 | 100 마나 |
| 마법 데미지 | 4 |
| 오답/타임아웃 직접 피해 | 0 (HP 감소 없음) |
| Phase A 바닥 장판 회피 실패 피해 | -25 |
| Phase B 보스 결전 마법 공격 | -15 |

**전투 흐름**:
- **Phase A (문제 구간)**: 정산 완료 기준 총 10문제. 런 8박 → 답안 2박 → 정답 시 별모으기 / 오답·타임아웃 시 좌·우 스텝 또는 점프 단일 바닥공격 회피. **오답 또는 타임아웃 자체로는 플레이어 HP가 차감되지 않으며 보스의 직접 반격도 없음**. 플레이어 피해는 오직 바닥공격 회피 실패 시에만 발생한다. 정답 직접 보스 피해는 0이고 마나 스펠 피해만 적용하되, 승리는 Phase B에서만 판정한다.
- **Phase B (보스 결전 구간)**: 모든 문제 완료 후 누적된 별가루, 성장한 수호신 깨비, 구출된 12종 미니언 군단과 함께 보스 결전에 돌입. 유저는 피버타임 별모으기 콤보 공격을 펼치고, 보스는 결전 마법 및 광폭화 패턴 시전.

**별 포인트와 전투 자원의 분리**:
- 정답 확정은 별 수집과 무관하게 기본 마나 +25와 콤보 +1을 보장한다.
- 별은 정답 후 `STAR_COLLECT` 구간에서만 수집되며, `Perfect / Good / Late / Miss` 리듬 판정과 별 포인트를 제공한다.
- 별은 챕터 클리어 등급용 `dream_guardian_stars`와 별도로 기록한다.
- 소비 가능한 별가루는 Perfect 4 / Good 3 / Late 2 / Miss 0으로 노트별 적립하며, Phase A에서는 소비하지 않는다.
- 오답/미응답 시에는 키노트 별이 생성되지 않으며, `HAZARD_EVADE`에서 좌스텝·우스텝·점프 중 단일 회피 공격이 가동된다.

### 3.2 모션 인식 시스템

**MediaPipe 구성**:
- Pose: `@mediapipe/pose@0.5` (Lite 모델, complexity=0)
- Hands: `@mediapipe/hands@0.4` (손바닥 중심 트래킹)
- 양쪽 모두 30fps 제한

**동작 감지**:

| 동작 | 감지 방식 | 게임 효과 |
|------|----------|----------|
| 제자리 달리기 | 어깨 상하 바운스 + 좌우 흔들림 + 손목 교차 거리 | 게이지 충전 |
| 스쿼트 | 어깨 Y가 기준선 대비 0.065 이상 하강 | 칼로리 계산 및 하체 운동 |
| 점프 | 어깨 Y가 기준선 대비 0.065 상승 + 속도 > 0.22/dt | 바닥 충격파/장판 회피 (`HAZARD_EVADE`) |
| 걸음 수 | 어깨 수직 이동 > 0.012, 최소 0.2초 간격 | 칼로리 계산용 |
| **양손 대각 X자 교차** | 왼손목-오른어깨 & 오른손목-왼어깨 동시 접근 (< 0.55 어깨너비, 0.4초 유지) | **서브메뉴 뒤로가기 / 인게임 일시정지(Pause) 모달 호출** |
| **양손 모으기 (합장)** | 양 손목 간 정규화 거리 < 0.22 (0.8초 호버 체류) | **메뉴 항목 선택 / 일시정지 팝업 버튼 선택 / 결과화면 복귀** |

**답안 선택 (한 팔 Zone 4/5 0s 무체류 즉시 판정)**:
- 런 8박 완료 직후 답안 창이 개방되며, 한 팔을 Zone 4(0번, 화면 좌측) 또는 Zone 5(1번, 화면 우측)에 두어 0초 무체류로 즉시 선택한다.
- 정적 손 위치 및 중앙에서 바깥 방향 동적 뻗기 모두 첫 프레임에 즉시 인정.
- 양팔 동시 유효(4+5 또는 동시 같은 존) 시 미선택(Strict Mutual Exclusion) 유지.
- 수직 점프 동작 오선택 차단(수직 속도 상한 검증) 및 키보드(1, 2)/터치 비상 fallback 완전 지원.
- 기존 골반 횡이동 및 체류 게이지/체류 충전음은 전면 폐기/제거됨.

**칼로리 공식**: `(steps × 0.04) + (squats × 0.35) + (jumps × 0.15)` kcal

**별 수집 안무 메커니즘**:
- **데이터 소스**: `fitness pattern.csv` 원본 데이터 360건 (Single 60, Double 100, Triple 100, Quad 100)
- CSV 한 패턴의 부위-존 쌍을 한 박에 하나의 `StarTarget`으로 순차 분해한다. 초기 버전은 동시에 여러 별을 요구하지 않는다.
- 각 별은 지정 커서가 목표 존에 비트 착지 순간 도달했는지 판정한다: Perfect `+/-0.12초`, Good `+/-0.25초`, Late `+/-0.40초`, 그 밖은 Miss.
- 시퀀스 생성기는 같은 부위 장거리 왕복, 직전 별의 동일 부위/동일 존 반복, 골반 최하단과 손 최상단의 Cross-Body 충돌을 차단한다.
- 기존 집합 덮기(Set Coverage)와 PartGate는 CSV 패턴의 안전성 검증 및 안무 후보 추출에 보존하며, 더 이상 좌/우 수학 답을 확정하지 않는다.
- **부위별 허용 구역 및 안전 제약 규칙**:
  - **양손 커서 (왼손 / 오른손)**: **전 존(1~11) 허용** (한 팔을 들어 반대편 옆구리를 늘리는 스트레칭 및 교차 도달 지원)
  - **머리 커서**: **중단 좌/우 존(4, 5)만 허용** (존 1~3은 점프로 순간 진입은 가능하나 체류 유지가 불가능하며, 2번은 직립 대기 시 머리가 위치하여 즉각 자동 선택되므로 완전 배제)
  - **골반 커서**: **하단 존(6, 8, 9, 10, 11)만 허용** (존 1~5 상단 이동 배제, 존 7번은 기본 직립 자세 시 골반 자연 위치로 출제 즉시 자동 선택되는 결함을 차단하기 위해 완전 배제)
  - **Cross-Body 연동 제약**: 골반이 최하단 존(9, 10, 11)에 위치할 때, 양손은 최상단 존(1, 2, 3) 배치 불가 (스쿼트 시 만세 동작의 물리적 한계 배제)
  - `HEAD_ZONES ∩ HIP_ZONES = ∅` 확립으로 머리와 골반이 동일 존을 요구하는 물리적 충돌 원천 배제
  - 캘리브레이션 기준선 대비 신체 변위(PartGate) 검증으로 단순 직립 시 오인식 차단
   - 별 수집 목표는 각 부위의 허용 구역과 안전 제약을 그대로 따른다.
- **시각 가이드 및 편의 시스템**:
   - **별 가이드**: 목표 존 마법진, 부위 색상 아이콘, 비행 궤적, 수축 타이밍 링을 함께 표시한다.
   - **첫 라운드 튜토리얼**: 중앙 복귀 → 좌/우 정답존 → 첫 별 수집 순으로 안내한다.
