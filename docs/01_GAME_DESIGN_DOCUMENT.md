# 꿈의 수호신 (Dream Guardian) - 게임 기획서 (GDD)

> **프로젝트명**: Dream Guardian (꿈의 수호신)
> **태그라인**: "생각하는 힘이, 나를 지킨다"
> **장르**: 체감형 피트니스 교육 RPG (Ring Fit Adventure 스타일)
> **플랫폼**: 모바일 웹 (PWA), 데스크톱 브라우저
> **타겟 유저**: 초등~중등 학생 (수학 학습 + 신체 활동)

---

## 1. 게임 컨셉

### 1.1 핵심 아이디어
- 웹캠 앞에서 **실제 운동**(제자리 달리기, 스쿼트, 점프, 팔 스트레칭)을 하면서
- **수학 문제**를 풀어 수호신에게 마나를 공급하고
- 수호신이 모은 마나로 **보스 몬스터를 물리치는** 체감형 RPG

### 1.2 세계관 (몽계 - 꿈의 세계)

**배경**: "몽계"는 아이들의 꿈으로 만들어진 세계. 이 세계에 어둠이 침투하면서 꿈이 무너지기 시작한다.

**주인공**: 아이의 꿈을 지키기 위해 태어난 작고 약한 수호 정령. "사고의 빛"(수학 문제 정답 시 발생하는 에너지)을 흡수하며 성장한다.

**4대 몬스터 + 최종 보스**:

| 챕터 | 몬스터 | 정체 | 수학 영역 |
|-------|--------|------|----------|
| Ch.1 | **포겟 (Forget)** | 기억을 지우는 안개 괴물 | 덧셈/뺄셈 |
| Ch.2 | **후다닥 (Hurry)** | 서두르게 만드는 번개 괴물 | 곱셈/나눗셈 |
| Ch.3 | **뒤죽박죽 (Jumble)** | 숫자를 뒤섞는 만화경 괴물 | 분수 |
| Ch.4 | **에라 (Give-up)** | "그냥 포기해"를 속삭이는 그림자 | 소수 |
| Ch.5 | **나이트메어 (Nightmare)** | 실패와 좌절을 먹고 자라는 최종 보스 | 전 영역 종합 |

**엔딩 메시지**: "실패는 너의 힘이 아니야. 다시 도전하는 그 순간이, 바로 나의 힘이 되는 거야."

### 1.3 차별점
| 항목 | 기존 수학 앱 | 본 게임 |
|------|-------------|---------|
| 입력 방식 | 터치/키보드 | 전신 모션 (4색 커서) |
| 운동 연계 | 없음 | 달리기·스쿼트·점프·스트레칭 |
| 피드백 | 정답/오답 텍스트 | 수호신 마법 캐스팅, 보스전 |
| 동기 부여 | 점수/별 | 스토리 진행 + 수호신 성장 + 운동 기록 |
| 음성 지원 | 없음 | 한국어 TTS 문제 읽기 |

## 2. 게임 루프 (Core Loop)

```
[메뉴 (챕터 선택)] → [서브레벨 선택] → [스토리 인트로 (3초)]
         ↓
  [보정 대기] — 코 가이드 박스 2초 대기
         ↓
  [달리기 페이즈]
  ├─ 제자리 달리기 → 게이지 충전 (100%)
  ├─ 점프 → 게이지 +25%
  ├─ (보스 공격) → 스쿼트로 방어 (실드)
  └─ 게이지 MAX → 문제 출제
         ↓
  [문제 페이즈]
  ├─ 한국어 TTS 문제 읽기 (2초 읽기 잠금)
  ├─ 2지선다 표시 (피트니스 존에 배치)
  ├─ 신체 커서로 답 선택 (1초 체류)
  ├─ 정답 → 마나 +25, 콤보 +1
  └─ 오답 → HP -25, 콤보 리셋
         ↓
  [마나 100 도달] → 수호신 마법 캐스팅 → 보스 HP -4
         ↓
  [보스 HP ≤ 0] → 결과 화면 (등급/별) → 다음 챕터 해금
         ↓
  [Ch.5 클리어] → 엔딩 컷신 (4페이즈) → 최종 결과
```

## 3. 시스템 설계

### 3.1 전투 시스템

| 파라미터 | 값 |
|----------|-----|
| 플레이어 HP | 100 |
| 보스 HP (Ch.1~4) | 10 |
| 보스 HP (Ch.5 나이트메어) | 20 |
| 정답 시 마나 획득 | +25 |
| 마법 시전 비용 | 100 마나 |
| 마법 데미지 | 4 |
| 오답 시 HP 감소 | -25 |
| 보스 공격 (스쿼트 방어 실패 시) | -15 |

**전투 흐름**: 정답 4개 → 마나 100 → 수호신 자동 시전 → 보스 -4 HP
- Ch.1~4: 보스 HP 10 → 최소 3회 시전 (정답 12개) 필요
- Ch.5: 보스 HP 20 → 최소 5회 시전 (정답 20개) 필요

### 3.2 모션 인식 시스템

**MediaPipe 구성**:
- Pose: `@mediapipe/pose@0.5` (Lite 모델, complexity=0)
- Hands: `@mediapipe/hands@0.4` (손바닥 중심 트래킹)
- 양쪽 모두 30fps 제한

**동작 감지**:

| 동작 | 감지 방식 | 게임 효과 |
|------|----------|----------|
| 제자리 달리기 | 어깨 상하 바운스 + 좌우 흔들림 + 손목 교차 거리 | 게이지 충전 |
| 스쿼트 | 어깨 Y가 기준선 대비 0.065 이상 하강 | 보스 공격 방어 (실드) |
| 점프 | 어깨 Y가 기준선 대비 0.065 상승 + 속도 > 0.22/dt | 게이지 +25% |
| 걸음 수 | 어깨 수직 이동 > 0.012, 최소 0.2초 간격 | 칼로리 계산용 |

**칼로리 공식**: `(steps × 0.04) + (squats × 0.35) + (jumps × 0.15)` kcal

### 3.3 답 선택 시스템 (answer-selection.js)

**4색 신체 커서**:

| 커서 | 색상 | 신체 부위 | 형태 |
|------|------|----------|------|
| 왼손 | 시안 `#28E6FF` | 손바닥 중심 (Hands) / 손목 (Pose fallback) | 원 |
| 오른손 | 노랑 `#FFCB4D` | 동일 | 원 |
| 어깨 | 보라 `#C889FF` | 더 많이 움직인 어깨 | 사각형 |
| 엉덩이 | 주황 `#FF865E` | 엉덩이 중점 | 다이아몬드 |

**10개 피트니스 존 레이아웃**:
```
[1 좌상] [2 상단 ] [3 우상]
[4 좌  ]  (답표시)  [5 우  ]
[6 좌하]  [7 중하 ] [8 우하 ]
[9 좌저] [10 하단 ] [11 우저]
```

**선택 메커니즘**:
- 2개의 답에 동일한 피트니스 존 세트가 할당되지만, 요구하는 커서 색상이 다름
- 레시피: 1~3개 커서 조합 (`leftHand`, `rightHand`, `shoulder`, `hip`)
- 존 안에서 **1초 연속 체류** 시 답 확정
- 중심 가중 충전: 존 중심 1.5배, 가장자리 0.75배
- 엉덩이 커서는 하단 존(6~10)만 사용 가능
- 어깨 커서는 중간존(4,5,6,7,8)만 사용 가능

### 3.4 문제 출제 시스템

**데이터 소스**: `questions.csv` 
- 12컬럼 CSV: Level, SubLevel, LevelTitle, SubLevelTitle, QuestionTemplate, AnswerEval, WrongEval, VarA~VarD, ShapeCode
- Ch.1~4: 해당 레벨 필터링
- Ch.5 (나이트메어): 전 레벨 랜덤 혼합

**안전한 수식 평가** (`question-evaluator.js`):
- 화이트리스트 함수만 허용: `rand`, `pick`, `gcd`, `factorial`, `sup`, `repeatMul`, `repeatAdd`, `Math.abs`
- `window`, `.constructor` 등 코드 인젝션 차단
- `{A}`, `{B}`, `{C}`, `{D}` 변수 치환

**한국어 TTS** (`question-speech.js`):
- 수학 표기 → 음성 변환: `1/2 + 3 × 4 = ?` → `"2분의 1 더하기 3 곱하기 4는?"`
- 3초 시작 타임아웃, 비블로킹 (음성이 게임 진행을 차단하지 않음)

### 3.6 오디오 엔진

**방식**: Web Audio API 프로시저럴 합성 (외부 음원 0개)

| 효과음 | 파형 | 용도 |
|--------|------|------|
| correct | 사인파 상행 3화음 (C5→E5→G5) | 정답 |
| wrong | 삼각파 150Hz 감쇠 | 오답 |
| hover | 사인파 800Hz 짧은 블립 | UI 호버 |
| start | 사인파 스윕 523→1046Hz | 시작/시전 |
| monster_hit | 노이즈 + 사각파 스윕 | 보스 피격 |
| player_hurt | 톱니파 200→50Hz | 플레이어 피격 |
| shield_deflect | 사인파 3화음 880→1320→1760 | 스쿼트 방어 성공 |
| jump_whoosh | 사인파 320→960 스윕 | 점프 |
| crystal_pickup | 삼각파 C6→E6 | 트랙 오브 수집 |
| warning | 톱니파 440→370 | 보스 공격 경고 |
| step_beat | 사인파 120→40Hz | 걸음 펄스 |
| shatter | 삼각파 1200→2000→800 | 파티클 파괴 |

**BGM**: Am 펜타토닉 아르페지오 (A4, C5, D5, E5, G5), 300ms 간격, 사인파 0.05 gain

## 4. 기술 스택
