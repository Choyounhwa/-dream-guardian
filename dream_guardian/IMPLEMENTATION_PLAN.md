# 《꿈의 수호신》 — 모션 수학 어드벤처 게임 기획서 & 구현 계획

## 1. 프로젝트 개요

기존 "마법 연금술 아카데미" 게임의 핵심 시스템(MediaPipe Pose 모션 인식, 수학 문제 엔진, Web Audio 사운드 등)을 기반으로,
새로운 스토리 **《꿈의 수호신》**에 맞는 **완전히 새로운 비주얼과 게임플레이**를 가진 게임을 제작합니다.

### 핵심 변경 사항

| 항목 | 기존 게임 | 새 게임 |
|---|---|---|
| **테마** | 중세 판타지 RPG (화염룡 vs 연금술사) | 꿈 세계 (몽계) — 수호신 vs 꿈속 괴물 |
| **색상 팔레트** | 다크 골드/화염 오렌지/루비 | **아이스블루/라벤더/은빛 빛/신비로운 보라** |
| **주인공** | 없음 (1인칭 마법사 시점) | **꼬마 수호신** (아이스블루 물/빛 테마 캐릭터) |
| **적** | 고대 화염룡 알렉스트라자 | **4종 꿈속 괴물** (포겟, 후다닥, 뒤죽박죽, 에라) + 최종보스 **나이트메어** |
| **수학 단계** | 9단계 47개 서브레벨 | **4단계** (덧뺄셈, 곱나눗셈, 분수, 소수) |
| **운동 모션** | 팔 스윙 달리기 only | **달리기 + 팔 좌우 흔들기 + 앉기(스쿼트) + 점프** |
| **문제 선택 방식** | 상단 모서리 Dwell (0.5초) | **전신 모션 선택** (왼쪽 팔 들기/오른쪽 팔 들기) |

> [!IMPORTANT]
> 기존 문제 CSV 파일(`questions.csv`, `questions_cleaned.csv`)은 **원본 그대로 유지**합니다.
> 새 게임은 Level 1~4 데이터만 필터링하여 사용합니다.

## 3. 스토리 & 월드 구조 — 4장 구성

### 1장 — 숫자의 숲 (덧뺄셈)
- **배경**: 부드러운 초록/청록빛 숲, 반딧불 같은 사고의 빛 파티클
- **괴물**: 깜빡괴물 **「포겟」** — 주변의 숫자와 길을 지워버림
- **보스 HP**: 10 (10문제)
- **운동 요구**: 기본 달리기 + 팔 좌우 흔들기

### 2장 — 곱셈의 성 (곱나눗셈)
- **배경**: 거대한 보라빛 성, 별빛 창문, 숫자가 벽돌처럼 쌓인 구조물
- **괴물**: 성급괴물 **「후다닥」** — 빠르게 공격, 서둘러 틀리게 만듦
- **보스 HP**: 10
- **운동 요구**: 달리기 + 팔 흔들기 + **점프 모션** 추가

### 3장 — 나눗셈의 미궁 (분수)
- **배경**: 끝없는 보라/분홍빛 미로, 거울에 비친 숫자들
- **괴물**: 헷갈림괴물 **「뒤죽박죽」** — 숫자와 기호를 뒤섞음
- **보스 HP**: 10
- **운동 요구**: 달리기 + 팔 흔들기 + 점프 + **스쿼트(앉기)** 추가

### 4장 — 소수의 사막 (소수)
- **배경**: 금빛/아이스블루 모래폭풍, 숫자의 별이 빛나는 밤하늘
- **괴물**: 포기괴물 **「에라」** — "그냥 포기해" 속삭임
- **보스 HP**: 10
- **운동 요구**: 전체 모션 활용 (달리기 + 팔 흔들기 + 점프 + 스쿼트)

### [최종 보스] 나이트메어
- 4장 모두 클리어 시 등장하는 최종 보스전
- 스토리 엔딩 연출 + 최고 난이도 혼합 문제 10문제

## 4. 운동 모션 시스템 (링핏 스타일)

### 4.1 감지할 모션 종류

MediaPipe Pose의 33개 관절 랜드마크를 활용하여 다음 4가지 운동을 감지합니다.

#### ① 달리기 (Running) — 기존 시스템 개선
- **감지 방식**: 양 어깨 Y좌표 교대 바운스 + 양손 교차 스윙
- **용도**: 문제 사이 마나 충전 (보스에게 달려가는 연출)
- **운동 강도**: 4~6초간 제자리 달리기

#### ② 팔 좌우 흔들기 (Arm Swing) — 정답 선택
- **감지 방식**: 양 손목(15, 16)의 X좌표가 어깨 바깥으로 크게 벗어나는 것을 감지
- **용도**: 정답 선택 (왼손을 크게 뻗으면 왼쪽 답, 오른손을 크게 뻗으면 오른쪽 답)
- **Dwell 시간**: 1.0초 유지 시 확정 (오판 방지)

#### ③ 스쿼트/앉기 (Squat)
- **감지 방식**: 양 어깨 Y좌표가 기준선(서 있을 때)보다 일정량 이상 내려감
- **용도**: 특수 방어 모션 — 괴물 공격 회피 또는 추가 마나 충전 보너스
- **판정**: 어깨 Y가 기준선에서 15% 이상 하강 시 감지

#### ④ 점프 (Jump)
- **감지 방식**: 양 어깨/엉덩이 Y좌표가 기준선보다 급격히 상승 (위로 올라감)
- **용도**: 특수 공격 모션 — 점프 시 사고의 빛 폭발 이펙트
- **판정**: 어깨 Y가 기준선에서 10% 이상 급상승 후 복귀

### 4.2 게임 플레이 흐름 (한 문제 사이클)

```
[달리기 페이즈] ─── 마나 게이지 충전 (제자리 달리기 4~6초)
       │
       ▼
[문제 표시 페이즈] ─── 수학 문제 + 2지선다 표시
       │
       ▼
[답안 선택 페이즈] ─── 왼팔/오른팔 크게 뻗어 선택 (1초 유지)
       │
       ├── [정답] → 수호신 공격 연출 → 보스 HP 감소 → 다음 문제
       │
       └── [오답] → 괴물 반격 연출 → 플레이어 HP 감소 → 추가 운동 요구
```

### 4.3 운동 강도 조절

| 항목 | 설정 |
|---|---|
| 기본 달리기 게이지 충전 시간 | 5초 |
| 오답 시 페널티 | +50% 추가 달리기 요구 |
| 3콤보 달성 시 보너스 | 점프 1회로 즉시 충전 |
| 스쿼트 보너스 | 마나 2배 충전 속도 |
