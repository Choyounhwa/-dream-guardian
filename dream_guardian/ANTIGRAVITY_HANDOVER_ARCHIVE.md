## 🚀 4. 테스트 및 실행 방법

### 방법 A: Node.js (npx http-server)
```powershell
cd "E:\AIAIAIAI\Arithmetic Game"
npx http-server -p 8080
```
브라우저에서 `http://localhost:8080/dream_guardian/` 접속

### 방법 B: Python 내장 서버
```powershell
cd "E:\AIAIAIAI\Arithmetic Game"
python -m http.server 8080
```
브라우저에서 `http://localhost:8080/dream_guardian/` 접속

> ⚠️ **주의 (웹캠 보안 정책)**:
> - 브라우저는 `localhost` 또는 `https://` 환경에서만 웹캠 접근을 허용합니다.
> - 스마트폰에서 테스트할 때는 같은 공유기(Wi-Fi)에 연결한 뒤, `mkcert` 등을 통한 로컬 SSL 적용 또는 Chrome의 `chrome://flags/#unsafely-treat-insecure-origin-as-secure` 설정을 활용하거나 ngrok 터널링을 이용해야 합니다.

### 테스트 조작키 (PC 환경 디버깅용):
- **Space**: 자세 정렬 즉시 통과, 달리기 마나 충전 (+15%), 스토리 스킵
- **← (왼쪽 화살표)**: 왼쪽 답안 선택
- **→ (오른쪽 화살표)**: 오른쪽 답안 선택
- **화면 클릭/터치**: 모서리/버튼 선택 및 화면 좌/우 클릭으로 답안 선택
