# 피트니스 존 카탈로그 / 출제 편집 가이드

## 목적

첨부된 국민체조 이미지를 바탕으로, 답안 선택을 유산소·스트레칭·가벼운 근력 이동으로 구성한다. 모든 존은 화면을 크게 벗어나지 않는 작은 범위의 움직임을 우선한다.

## 현재 입력 커서

|커서|실제 추적점|색|운동 의미|
|---|---|---|---|
|`leftHand`|MediaPipe Hands의 왼손 손바닥 중앙(랜드마크 9)|시안|왼팔 도달·팔 돌리기·상체 스트레칭|
|`rightHand`|MediaPipe Hands의 오른손 손바닥 중앙(랜드마크 9)|노랑|오른팔 도달·팔 돌리기·상체 스트레칭|
|`shoulder`|더 많이 움직인 왼쪽 또는 오른쪽 어깨|보라|한쪽 어깨 올리기/굴리기·몸통 측면 이동|
|`hip`|양 골반 중점|주황|골반 회전·체중 이동·미니 스쿼트|

손은 손목이 아닌 손바닥 중앙을 판정한다. 양손이 필요한 답은 두 손의 색상 요구를 동시에 충족해야 한다. 어깨는 한쪽만 이동해도 보라 커서 하나로 입력된다.

## 국민체조 기반 존 해석

첨부 이미지의 큰 동작을 웹캠 화면에서 안전하게 줄인 버전이다. 깊은 굴곡·점프는 강제하지 않는다.

|국민체조 참고|권장 커서|피트니스 존|화면 밖 방지용 축소 동작|효과 의도|
|---|---|---|---|---|
|1 팔 앞·옆으로 내리기|왼손/오른손|1, 3, 4, 5|한 손을 어깨 높이에서 작은 대각선/옆 이동|어깨 가동|
|1 팔 올리기|양손|1+3 또는 2|양손을 머리보다 약간 높게|광배·옆구리 스트레칭|
|2 무릎 굽혀 펴기|골반|7, 9|엉덩이를 작게 낮추는 미니 스쿼트|하체 가동|
|3 팔 돌려 흔들기|왼손/오른손|1, 3, 6, 10|팔을 작게 원형으로 돌린 뒤 해당 존 유지|어깨 워밍업|
|4 몸통 돌리기|어깨 또는 골반|4, 5|상체/골반을 좌우로 작게 회전|몸통 가동|
|5 가슴 젖히기|어깨|2|어깨를 뒤로 열고 약간 위로 이동|가슴 열기|
|6 몸 옆으로 굽히기|왼손 + 어깨|1/3 또는 4/5|한 손을 옆으로, 반대 어깨는 안정|옆구리 스트레칭|
|7 몸 앞으로 굽히기|양손 + 골반|8, 9, 10|손은 허벅지/무릎 방향, 골반은 아래로|햄스트링/등 가동|
|8 몸 돌려 팔 돌리기|양손 또는 어깨|4, 5|작은 몸통 회전과 팔 이동|협응·가동성|
|9 노젓기|양손|8+10 또는 6+10|양손을 앞뒤 대각선으로 교대로 이동|유산소 리듬|
|10 다리 들어 뛰기|골반|2, 7|한쪽 무릎을 살짝 들거나 골반 위 이동|고관절 가동|
|11 무릎 굽혀 팔 펴기|양손 + 골반|8/10 + 9|미니 스쿼트와 한/양손 전방 이동|전신 협응|
|12 팔벌려 숨쉬기|양손|1+3|두 손을 넓게 벌려 위 대각선 이동|호흡·가슴 열기|

## 10개 피트니스 존

`answer-selection.js`의 `ZONES`가 단일 정의다.

|ID|이름|추천 커서|비고|
|---|---|---|---|
|1|왼쪽 위|왼손, 어깨|한손 대각선/어깨 올림|
|2|위|양손, 어깨, 골반|골반은 출제 금지; 양팔 위로|
|3|오른쪽 위|오른손, 어깨|한손 대각선/어깨 올림|
|4|왼쪽|왼손, 어깨|옆 도달/몸통 이동|
|5|오른쪽|오른손, 어깨|옆 도달/몸통 이동|
|6|왼쪽 아래|손, 골반|작은 앞으로 굽힘/체중 이동|
|7|가운데 아래|손, 골반|미니 스쿼트/중앙 준비|
|8|아래 왼쪽|손, 골반|낮은 왼쪽 도달|
|9|아래|손, 골반|양손 아래/미니 스쿼트|
|10|아래 오른쪽|손, 골반|낮은 오른쪽 도달|

골반은 물리적으로 상단에 올리기 어렵기 때문에 `6~10`만 허용한다.

## 출제 편집 방법

파일: `answer-selection.js`

### 색상/형태 변경

`CURSORS`에서 `label`, `color`, `shape`를 수정한다.

### 피트니스 존 추가/삭제

1. `ZONES` 배열에 `{id, label, x, y, w, h}`를 추가/수정한다.
2. 다른 모든 존과 겹치지 않도록 유지한다.
3. 골반을 허용하려면 `HIP_ZONES`에 ID를 추가한다.
4. 상체 커서를 허용하려면 `UPPER_ZONES`에 ID를 추가한다.
5. `node dream_guardian/answer-selection.test.cjs`를 실행한다.

### 동작 조합 추가/삭제

`RECIPES` 배열의 항목은 1~3개의 커서 키다.

```js
['leftHand', 'hip']
['leftHand', 'rightHand', 'shoulder']
```

현재 출제기는 동일한 문제에서 좌/우 답안의 커서 개수를 항상 같게 만든다. 좌/우 답안은 같은 색을 공유하지 않으며, 피트니스존 하나에는 커서 색 하나만 배정한다. 따라서 양손/손+골반 문제는 각 커서를 서로 다른 피트니스존에 넣어 동시에 유지해야 한다.

## 간단 편집기: 코드 없이 조합 검토하기

`FITNESS_ZONE_EDITOR.md`에는 피트니스존 1~10, 커서 색상, 국민체조 동작, 추천 조합을 표 형태로 정리했다. 새 존/포즈는 먼저 그 문서에서 다음을 정한 뒤 코드에 반영한다.

1. 어떤 커서 색(왼손/오른손/어깨/골반)을 쓸지
2. 어느 피트니스존에 둘지
3. 한 존에 합칠 커서가 있는지
4. 골반이면 하단 존인지
5. 좌/우 답안이 같은 커서 수인지

검토가 끝난 조합만 `answer-selection.js`의 `RECIPES` 또는 출제 규칙으로 옮긴다.

### 민감도 조정

`controlMarkers()`의 `gain` 값을 바꾼다.

- 작은 값: 적은 실제 이동으로 더 먼 존까지 도달
- 큰 값: 더 큰 실제 운동 범위를 요구
- 권장 순서: 손 → 어깨 → 골반 순으로 실기기에서 0.05씩 조정

### 중심 충전 보정

`Gate.update()`의 `rate`는 존 중심에서 최대 1.5배, 경계 부근에서 최소 0.75배 충전된다. 경계 진입만으로는 느리게, 중심 유지로는 빠르게 선택된다.

## 안전 원칙

- 화면 밖으로 팔·골반을 과도하게 보내는 동작은 피한다.
- 깊은 스쿼트, 점프, 허리 과신전은 답안 확정 조건으로 강제하지 않는다.
- 피로·통증·어지러움이 있으면 중지한다.
- 운동 효과는 의도이며 의료/운동 처방이 아니다.
