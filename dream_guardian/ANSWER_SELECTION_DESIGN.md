# 색상 스켈레톤 커서 / 11구역 답안 선택 설계

> **역사/안무 안전성 참고 문서**: 이 문서의 Set Coverage·다중 신체 커서·체류 판정은 현재 수학 답안 선택 규범이 아니다. 현행 답안은 #229/#224 계약에 따라 `ANSWER_SELECT`에서 한 팔을 Zone 4(0번) 또는 Zone 5(1번)에 두는 즉시(0초 무체류) 확정한다. 아래 11존·부위 제약은 `STAR_COLLECT` 안무 후보 안전성에만 재사용하며, 구형 답안 화면과 자세 가이드는 #233에서 제거한다.

## 목적

초기 설계에서는 문제의 정답·오답을 계산한 뒤 색상 커서를 지정 영역에 유지해 확정했다. 이 방식은 현행 수학 답안 경로에서 폐기되었고, 11존 안무 데이터의 안전성 검토 자료로만 남긴다.

색상은 정답 힌트가 아니라 움직일 신체 부위를 뜻한다. 좌측/우측 답안은 같은 수의 색상 조각을 가지며, 계산해야 정답을 알 수 있다. **활성 피트니스존은 좌/우 답안이 공용으로 사용**한다. 즉 존의 위치가 정답/오답별로 달라지는 것이 아니라, 플레이어가 계산한 답의 색상 커서를 공용 존으로 옮기는 방식이다.

## 스켈레톤 커서

| 커서 | 색상 | 실제 표시 | 입력 좌표 | 
|---|---|---|---|
| 왼손 | 시안 `#28E6FF` | 원손바닥 크기 원 + 약한 동심 링 | 왼쪽 손 중지손가락 | 
| 오른손 | 노랑 `#FFCB4D` | 손바닥크기 원 + 약한 동심 링 | 오른쪽 중지손가락 |
| 머리 | 보라 `#C889FF` | 눈코입을 포함한 크기의 타원, 입력은 중점 | 눈코입 트레킹 |
| 골반 | 주황 `#FF865E` | 골반 폭 마름모, 입력은 중점 | 양 골반 중점 |


- 연결선은 20% 투명도, 커서 형태는 100% 이다.
- 4색 커서는 스켈레톤 관절 위에 직접 렌더링된다. 커서가 화면 밖으로 이탈할 경우, 상위 스켈레톤 계층(손바닥→손목→전완→팔꿈치→상완→어깨)을 따라 자동으로 가용한 관절 위치로 Fallback하여 화면 내 좌표를 유지한다.
- 실제 영상에서 화면 바깥까지 팔·골반을 이동할 필요가 없다.

## 답안

> 이 절은 구형 답안 시각 설계 기록이다. 현행 좌/우 수학 답안은 Zone 4/5 고정 버튼이며 색상 조각, 묶음 기호, 1~3부위 동시 자세를 정답 확정에 사용하지 않는다.

- 답안은 좌/우 두 개
- 답안 버튼은 **둥근 사각형(RoundRect)** 형태를 유지한다.
- 색상 요구가 1개면 사각형 전체를 해당 색 테두리로 표시한다.
- 2개면 사각형 중심을 기점으로 **방사형(Radial)** 1/2 분할, 3개면 1/3 분할로 색상을 나눈다.
- 두 답안은 항상 동일한 조각 수를 사용한다. 현재 커서 색이 4개라 **1색 또는 2색 조합**만 출제한다. 3색 vs 3색은 색을 겹치지 않게 만들 수 없어, 새 커서 색을 추가하기 전에는 출제하지 않는다.
- 한 답안의 요구 커서는 1~3개이며, 그 요구 커서가 각각 배정된 구역에 동시에 들어와야 한다.
- 요구하지 않은 커서가 어떤 구역에 들어가도 무시한다.
- 좌/우 답안은 같은 색을 공유하지 않는다. 따라서 색상만 보아도 어느 답안에 필요한 커서인지 구분할 수 있다.
- 답안 버튼 하단에 요구 부위 아이콘(손/머리/골반)과 묶음 기호(`( )` 함께 한 존에, `|` 각각 다른 존에)가 표시된다.

각 답안 버튼마다 **"어떤 신체 부위(커서)를 어느 피트니스 존에 넣어야 하는지"**가 결정됩니다.
    답안이 요구하는 커서가 1개 - 1개의 피트니스존 활성화 
    답안이 요구하는 커서가 2개 - 2개의 피트니스존 활성화 
    답안이 요구하는 커서가 3개 - 3개의 피트니스존 활성화 

예를 들어 
1. 좌정답(노랑) 우정답(시안 색)이고 문제에 대한 답이 좌 정답일때  정답 판정은 노랑커서(오른손)
	피트니스존은 1개 활성화
	오른손이 활성화된 피트니스존에 머무르면 정답
	왼손이 피트니스존에 머무르면 오답 
2. 우정답(노랑,시안) 좌정답(노랑보라) 이고 답이 우정답 일때 정답판정은 노랑,시안커서(왼손,오른손)
	피트니스존 1개 혹은 2개 활성화 
	오른손과 왼손이 활성존에 머무르면 정답 
	오른손과 머리가 활성존에 머무르면 오답
	피트니스존1개 - 왼손오른손이 함께 피트니스존에 위치
	피트니스존2개 - 왼손 / 오른손이 각각 피트니스존에 위치 (어느것이든 상관이 없음) 
	


## 11구역 해석과 배치 

```
┌─────────────┬──────────┬────────────┐
│ 1           │ 2        │ 3          │
├─────────┬───┴──────────┴──┬─────────┤
│ 4       │                 │5        │
├─────────┤      문제       ├──────────┤
│     답          공간            답
├─────────┤────────────────├──────────┤
│     6   │        7       │     8    │
├─────────┴┬───────────────├──────────┤
│      9   │       10      │      11  │
└──────────┴───────────────┴──────────┘
```

- 화면 전체 기준 좌표이며 중앙의 문제와 과 겹치지 않도록 빈 공간을 남긴다.
- 활성화된 구역은 **직접 제작한 이미지(3중 회전 마법진 등)를 적용**하여 시각화한다. 존 배경 아래에 마법진 이미지가 깔리며, 충전 시 네온 테두리 및 충전 바가 함께 표시된다.
- 한 문제의 활성 피트니스존은 좌/우 답안 모두에게 동일하다. **피트니스존에는 2개의 답안이 요구하는 스켈레톤 부위가 아니면 충전되지 않는다. ** 
- 골반 요구는 `6, 8, 9, 10, 11` 중 하나에만 배정된다. 기본 직립 위치인 7번은 문제 출제 즉시 자동 선택되는 결함을 방지하기 위해 출제에서 배제된다.
- 어깨의 요구는 `4,5,6,7,8` 중 하나에만 배정된다.

## 시각 가이드 및 사용자 보조

1. **실루엣 가이드 오버레이 (PostureGuideRenderer)**:
   - 각 문제마다 목표 자세를 반투명 스틱맨 실루엣으로 캔버스에 표시.
   - 목표 피트니스 존에 해당 부위 색상의 네온 테두리 글로우 및 중앙 부위 아이콘 표시.
2. **첫 문제 유도 화살표 (Arrow Hint)**:
   - 스테이지 시작 후 **첫 번째 문제에서만** 커서 위치 → 목표 피트니스 존 중심을 잇는 방향 유도 화살표 렌더링.
   - 첫 문제 해결 이후부터는 자연스러운 조작 유도를 위해 화살표가 표시되지 않음.
3. **달리기 동적 보정**:
   - 제자리 달리기 중 전후좌우 이동으로 인한 좌표 드리프트 동적 보정은 정밀 설계를 위해 보류.

## 출제 규칙

1. 색상 수 1 또는 2 중 하나를 무작위로 선택한다.
2. 좌측·우측 답안에 같은 색상 수의 요구 커서를 뽑는다.
3. 피트니스존 수는 요구 색상 수와 같게 선택하고, 좌/우 답안 모두가 쓸 수 있는 공용 존으로 설정한다. 
4. 답안에서 요구하는 커서의 색상은 답안상자 중앙을 기점으로 방사형으로 분할한다 1,1/2,1/3
5. 답 값은 좌/우에 무작위 배치한다. 색상 조합/구역 위치는 정답 여부와 독립적이다.



## 유지 판정

> 아래 체류 규칙은 구형 Set Coverage 답안 판정 기록이며 현행 `ANSWER_SELECT`에는 적용하지 않는다. 현재 답안은 0초 무체류이고, 별 노트는 시간 판정창(Perfect/Good/Late/Miss)을 사용한다.

1. 문제 출제 후 **즉시 입력 허용** (별도의 읽기 잠금 없음). 피트니스존 체류 시간(Dwell Time)이 Tier별로 0.7초~1.2초로 충분하여 우발적 즉시 선택이 방지된다.
2. 요구 커서를 활성화된 구역으로 이동
3. Tier별 체류 시간(0.7~1.2초) 연속 유지. 경계에서는 느리게(0.75배), 중심에서는 빠르게(1.5배) 충전된다.
4. 하나라도 구역에서 벗어나면 충전이 서서히 줄어든다.
5. 양쪽 답안이 동시에 충족되면 데드락 방지(Deadlock Guard)로 양쪽 모두 급속 감쇠(3.0배)한다.

요구하지 않은 커서는 무시한다. 

## 테스트

검증 항목:

- 1~3 색상 조각 수의 좌우 동등성
- 요구 구역의 고유성
- 상위 스켈레톤 Fallback 좌표 유지
- 구역 경계의 반열린 범위
