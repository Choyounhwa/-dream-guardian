# 색상 스켈레톤 커서 / 10구역 답안 선택 설계

## 목적

문제의 정답·오답을 계산으로 고른 다음, 해당 답안 칸에 표시된 색상 조합과 같은 스켈레톤 커서를 지정된 영역에 동시에 놓고 **1초 유지**해 확정한다.

색상은 정답 힌트가 아니라 움직일 신체 부위를 뜻한다. 좌측/우측 답안은 같은 수의 색상 조각을 가지며, 계산해야 정답을 알 수 있다. **활성 피트니스존은 좌/우 답안이 공용으로 사용**한다. 즉 존의 위치가 정답/오답별로 달라지는 것이 아니라, 플레이어가 계산한 답의 색상 커서를 공용 존으로 옮기는 방식이다.

## 스켈레톤 커서

| 커서 | 색상 | 실제 표시 | 입력 좌표 |
|---|---|---|---|
| 왼손 | 시안 `#28E6FF` | 원 + 약한 동심 링 | 왼쪽 손목 |
| 오른손 | 노랑 `#FFCB4D` | 원 + 약한 동심 링 | 오른쪽 손목 |
| 어깨 | 보라 `#C889FF` | 양 어깨 사각형, 입력은 중점 | 양 어깨 중점 |
| 골반 | 주황 `#FF865E` | 골반 폭 역삼각형, 입력은 중점 | 양 골반 중점 |

- 머리 위치는 노랑 타원 50% 투명도로 표시하지만 답안 커서는 아니다.
- 연결선은 10% 투명도, 커서 형태는 100% 불투명도다.
- 문제 화면의 조작판에는 같은 색상/형태의 **제어 커서**가 표시된다. 이는 실제 스켈레톤의 준비 자세 대비 작은 이동을 확대한 판정 위치다.
- 실제 영상에서 화면 바깥까지 팔·골반을 이동할 필요가 없다.

## 답안 원

- 답안은 좌/우 두 개의 큰 원이다.
- 색상 요구가 1개면 원 전체를 해당 색으로 채운다.
- 2개면 원 중심을 지나 1/2씩, 3개면 원 중심을 지나 1/3씩 세로 분할한다.
- 두 답안은 항상 동일한 조각 수를 사용한다. 현재 커서 색이 4개라 **1색 또는 2색 조합**만 출제한다. 3색 vs 3색은 색을 겹치지 않게 만들 수 없어, 새 커서 색을 추가하기 전에는 출제하지 않는다.
- 한 답안의 요구 커서는 1~3개이며, 그 요구 커서가 각각 배정된 구역에 동시에 들어와야 한다.
- 요구하지 않은 커서가 어떤 구역에 들어가도 무시한다.
- 좌/우 답안은 같은 색을 공유하지 않는다. 따라서 색상만 보아도 어느 답안에 필요한 커서인지 구분할 수 있다.
- 플레이 화면의 실제 영상 스켈레톤에는 색상 커서를 중복 렌더링하지 않는다. 색상 커서는 조작판의 제어 커서만 사용하며, 영상에는 중립 관절/위치 표식만 남긴다.

## 10구역

```
  [1 왼쪽 위] [2 위             ] [3 오른쪽 위]
  [4 왼쪽   ]        답안 원       [5 오른쪽   ]
  [6 왼쪽 아래] [7 가운데 아래    ]
  [8 아래 왼쪽] [9 아래] [10 아래 오른쪽]
```

- 화면 전체 기준 좌표이며 중앙의 답안 원과 겹치지 않도록 빈 공간을 남긴다.
- 활성화된 구역은 요구 커서의 색으로 테두리·약한 채움·우웅우웅 펄스 효과를 표시한다.
- 펄스는 구역 크기에 맞춰 동심원이 바깥으로 커지며 투명해진다.
- 한 문제의 활성 피트니스존은 좌/우 답안 모두에게 동일하다. **피트니스존 하나에는 커서 색 하나만** 존재하며, 한 존에 두 색을 겹쳐 배정하지 않는다.
- 골반 요구는 `6, 7, 8, 9, 10` 중 하나에만 배정된다. 골반이 중앙 상단까지 올라가야 하는 조합은 만들지 않는다.

## 출제 규칙

1. 색상 수 1 또는 2 중 하나를 무작위로 선택한다.
2. 좌측·우측 답안에 같은 색상 수의 요구 커서를 뽑는다.
3. 피트니스존 수는 요구 색상 수와 같게 선택하고, 좌/우 답안 모두가 쓸 수 있는 공용 존으로 설정한다. 한 피트니스존에 두 색을 겹쳐 배정하지 않는다.
4. 골반이 포함되면 골반 구역은 하단 그룹(6~10)으로, 어깨는 4~7로 제한한다.
5. 답 값은 좌/우에 무작위 배치한다. 색상 조합/구역 위치는 정답 여부와 독립적이다.

현재 조합 목록은 `answer-selection.js`의 `RECIPES`, 구역은 `ZONES`, 색상은 `CURSORS`에서 수정한다.

## 유지 판정

1. 문제 출제 뒤 2초 확인 시간
2. 중앙에서 손을 내리고 0.6초 준비
3. 요구 커서를 모두 해당 구역으로 이동
4. 1초 연속 유지. 경계에서는 느리게, 중심에서는 빠르게 충전된다.
5. 하나라도 구역에서 벗어나면 유지 시간 초기화

요구하지 않은 커서는 무시한다. 두 답안의 요구 세트가 동시에 충족되는 경우에는 확정하지 않는다.

## 테스트

```powershell
node dream_guardian/answer-selection.test.cjs
```

검증 항목:

- 1~3 색상 조각 수의 좌우 동등성
- 요구 구역의 고유성
- 골반 하단 구역 제약
- 준비 자세 및 제어 좌표 변환
- 구역 경계의 반열린 범위

실기기에서 조정할 값은 `answer-selection.js`의 `controlMarkers()` 안의 `gain`이다. 값이 작으면 작은 움직임으로 더 먼 구역에 도달한다.
