# 피트니스존 조합 편집 시트

이 문서는 코드 수정 전 새 답안 조합을 검토하기 위한 편집용 시트다. 표의 `[ ]`를 채우고 아래 검증표를 통과한 조합만 구현한다.

## 커서 색상

|키|색상|입력 점|안전한 주 움직임|
|---|---|---|---|
|`leftHand`|시안|왼손 손바닥 중앙|작은 팔 도달, 팔 돌리기|
|`rightHand`|노랑|오른손 손바닥 중앙|작은 팔 도달, 팔 돌리기|
|`shoulder`|보라|더 많이 움직인 한쪽 어깨|어깨 들기, 몸통 회전|
|`hip`|주황|양 골반 중점|체중 이동, 미니 스쿼트|

## 새 문제 조합 작성 카드

```
조합 이름: [                         ]
운동 의도: [유산소 / 가동성 / 스트레칭 / 협응]

좌측 답안 요구 색: [             ]  개수: [1/2/3]
  - [커서] → [피트니스존]
  - [커서] → [피트니스존]
  - [커서] → [피트니스존]

우측 답안 요구 색: [             ]  개수: [1/2/3]
  - [커서] → [피트니스존]
  - [커서] → [피트니스존]
  - [커서] → [피트니스존]
```

## 검증 체크

- [ ] 좌/우 답안의 요구 색상 수가 동일하다.
- [ ] 답안 하나당 1~2 색상이다. (3색 vs 3색은 현재 4색 커서 체계에서 색상 비공유를 만족할 수 없음)
- [ ] 각 요구 색상은 왼쪽/오른쪽/어깨/골반 중 하나다.
- [ ] 골반은 존 6~10에만 배정했다.
- [ ] 좌/우 답안이 같은 커서 색을 공유하지 않는다.
- [ ] 좌/우 답안은 동일한 피트니스존 세트를 공유한다.
- [ ] 같은 문제에서 피트니스존 하나에 둘 이상의 커서 색을 배정하지 않는다.
- [ ] 팔을 화면 밖으로 과도하게 뻗지 않아도 되는가.
- [ ] 국민체조의 깊은 동작을 답 선택의 필수 조건으로 과도하게 강제하지 않는가.

## 코드 반영 위치

- 색상/형태: `answer-selection.js` → `CURSORS`
- 존 좌표: `answer-selection.js` → `ZONES`
- 골반 존 제한: `HIP_ZONES`
- 가능한 색상 조합: `RECIPES`
- 작은/큰 움직임 민감도: `controlMarkers()` → `gain`
- 충전 시간: `HOLD_SECONDS`

반영 후 다음을 실행한다.

```powershell
node dream_guardian/answer-selection.test.cjs
node dream_guardian/runtime.test.cjs
```
