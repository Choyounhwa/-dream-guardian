## 조작법

### 모바일 (핸드폰)
1. **메뉴**: 챕터 버튼 터치
2. **자세 정렬**: 화면 중앙에 몸 맞추기 (또는 터치로 스킵)
3. **달리기**: 제자리에서 팔 흔들며 달리기
4. **문제 풀기**: 왼팔 또는 오른팔을 크게 뻗어 1초 유지 (또는 화면 좌/우 터치)

### PC (테스트용)
1. **메뉴**: 클릭
2. **자세 정렬**: 스페이스바로 스킵
3. **달리기**: 스페이스바로 마나 충전
4. **문제 풀기**: ← / → 화살표 키

## 테스트 방법

### 로컬 서버로 실행
```bash
cd "E:\AIAIAIAI\Arithmetic Game"
npx http-server -p 8080
# 브라우저에서 http://localhost:8080/dream_guardian/ 접속
```

### 또는 Python 서버
```bash
cd "E:\AIAIAIAI\Arithmetic Game"
python -m http.server 8080
# 브라우저에서 http://localhost:8080/dream_guardian/ 접속
```

> [!IMPORTANT]
> 카메라 권한이 필요합니다. HTTPS 또는 localhost에서만 카메라가 동작합니다.
> 모바일에서 테스트할 경우 같은 네트워크에서 PC의 IP:8080으로 접속하세요.

## 향후 개선 가능 사항
- 스쿼트/점프 모션 감지 추가 (현재 달리기 + 팔 뻗기만 구현)
- 미니언 시스템 (아군 빛 정령 vs 적 그림자 정령)
- 더 풍부한 파티클 이펙트
- 엔딩 컷씬 ("실패는 너의 힘이 아니야. 다시 해보는 순간, 그것은 나의 힘이니까.")
- 로컬스토리지 기반 최단 시간 명예의 전당
