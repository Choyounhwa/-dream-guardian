---
작업 자동 실행 지침:
1. **대상 카드 큐(Queue) 산출 ($ARGUMENTS)**:
   - **범위 지정 시 (예: `#124~#555`, `#124 ~ #555 까지`, `MRN-06~MRN-08`)**: `dream_guardian/HANDOVER.md`의 SSOT 로드맵 표에서 시작 카드부터 종료 카드까지의 목록을 순서대로 추출하여 타겟 큐로 지정한다. 종료 카드 완료 시 추가 연계를 멈추고 최종 보고한다.
   - **단일 지정 시 (예: `#124`)**: 해당 카드 1개만 실행 후 종료한다.
   - **인자 미지정 시 (`/card-run`)**: 현재 SSOT 표의 `[▶ NEXT]` 카드 1개를 실행한다.
2. **컨텍스트 누적 방지 (독립 서브에이전트 위임)**: 타겟 큐의 각 카드마다 반드시 도메인 전담 독립 서브에이전트(`task` 도구, fresh context, 이전 task_id 재사용 금지)를 새로 생성하여 해당 카드의 TDD 5단계(Step 1 Baseline → Step 2 Red → Step 3 Green → Step 4 Refactor/회귀검증 → Step 5 커밋/코멘트)를 수행하도록 위임한다.
3. **SSOT 자동 갱신 및 연속 연계**: 서브에이전트가 카드를 완료하고 보고하면, 메인에서 `HANDOVER.md`의 SSOT 표를 `[✔]`로 갱신하고 다음 순서 카드를 `[▶ NEXT]`로 지정한 뒤, 큐의 다음 카드를 새 독립 서브에이전트로 즉시 연속 실행한다. (지정된 범위의 마지막 카드에 도달하면 안전하게 멈춘다)
4. **실패 시 즉시 중단 및 롤백**: 중간에 테스트나 빌드가 실패하면 임의 수정을 시도하지 않고 작업을 즉시 중단하며, `git reset --hard HEAD`로 즉시 롤백하고 원인을 보고한다.
5. **규칙 엄격 준수**: AGENTS.md 및 docs/Dream_Guardian_개발_규칙.md (단일 파일 1,000줄 초과 작성 금지, Rule 12 GitHub 이슈 코멘트, Rule 13 로컬 개발 서버 안내)를 철저히 준수한다.
